# Projeto 5 — Transformers

## Descrição

O Projeto 5 da UC de Redes Neurais consiste no desenvolvimento de uma aplicação utilizando a arquitetura **Transformer**.

A aplicação pode ser escolhida livremente, incluindo exemplos como:

- **Encoder-only:** classificação de textos.
- **Decoder-only:** geração de textos.
- **Encoder-decoder:** tradução automática.

## Requisitos

- Escolher uma aplicação que utilize Transformers.
- Implementar e testar o modelo na tarefa escolhida.
- É permitido utilizar modelos pré-treinados, desde que seja realizado algum tipo de **Transfer Learning ou Fine-tuning**.
- Avaliar os resultados obtidos.

## Objetivo

Explorar o funcionamento e a aplicação de redes Transformers em uma tarefa prática, analisando seu desempenho e os resultados obtidos.
